## 👨‍💻 About Me

I build **production-ready GenAI systems** — solo, end to end.

My flagship project, **EmpathEase**, is a multimodal AI mental health companion that fuses facial expression recognition, voice tone analysis, and multilingual NLP using **MuRIL** — making it accessible in Hindi, English, and Hinglish to 500M+ native speakers. The entire system runs on a locally-hosted **Llama 3** model via **FastAPI microservices and Docker** for private, low-latency therapeutic dialogue.

Not a tutorial clone. Built from scratch — dataset preprocessing, model training, microservices architecture, and containerized deployment.

## 🚀 Featured Projects

### 🧠 [EmpathEase — Multimodal AI Mental Health Companion](https://github.com/Abhisheksnegi10/EmpathEase)

> Real-time multimodal AI therapy assistant — facial affect + vocal prosody + multilingual text emotion → context-aware therapeutic response. **Built solo. End to end.**

**6-Layer Production Architecture:**

| Layer | What it does |
|-------|-------------|
| 🎭 Perception | FER-2013 CNN (80%+ accuracy) + Sarvam STT + MuRIL NLP |
| 🔀 Fusion | Emotional state engine with trajectory tracking |
| 🧩 Post-Processing | Cognitive distortion flags, incongruence detection |
| 🆘 Crisis Detection | Hard-coded safety protocol — LLM bypassed at urgent level |
| 🤖 Therapy Engine | Llama 3.1 8B (local) → Groq API → Claude API |
| ⚡ Infrastructure | FastAPI + Docker + React + WebSocket + PostgreSQL |

**Stack:** `PyTorch` `MuRIL` `Llama 3` `Ollama` `LangChain` `FastAPI` `Docker` `React` `Sarvam AI` `DPDP 2023`

[📐 View Full System Architecture →](empathease_architecture.html)
